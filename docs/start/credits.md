## Port

The port, its tools and this documentation were produced by the project maintainer with AI assistance.

## Third-party software used in the port

| Software | Use |
|---|---|
| Unity 6000.3.8f1 | Target engine |
| Unity 4.0.1f2 | Reference engine for behaviour comparisons ("oracle" builds); not shipped |
| AssetRipper | Export of the original scenes, prefabs and assets into a Unity project |
| ILSpy / ICSharpCode.Decompiler | Decompilation of the shipped managed assemblies |
| IDA Pro | Analysis of the Unity 4 and Unity 6 native engine binaries to establish engine behaviour |
| NGUI (as shipped in the original) | User interface; the original version is kept |
| Python | Build-time conversion and verification tools |

Third-party libraries that were shipped inside the original game (for example NGUI and the JSON parser) are part of the original
code and remain under their own terms.
